# 🎮 儿童识字游戏

专为 5-7 岁儿童设计的中英文识字游戏，支持中文汉字和英文单词学习，内含 8 种趣味游戏模式，寓教于乐。

---

## ✨ 功能特色

- 🌏 **中英双语**：支持中文识字和英文单词两种模式随时切换
- 🎯 **三档难度**：简单 / 中等 / 困难，循序渐进
- 🎨 **5 种主题**：粉红梦幻、蓝天白云、绿色森林、紫色魔法、彩虹缤纷
- 🔊 **语音朗读**：自动朗读单词发音，帮助孩子建立语感
- 💾 **自动存档**：记住语言、难度、主题偏好，下次打开继续

---

## 🕹️ 游戏模式

| 模式 | 说明 |
|------|------|
| 📖 学习模式 | 翻卡片学习字词，点击卡片朗读发音 |
| ✏️ 测验模式 | 四选一答题，测试认字效果 |
| 🧩 组词游戏 | 选字组成词语，学习常用词汇 |
| 🔗 连连看 | 将汉字与拼音/释义配对连线 |
| 🐹 打地鼠 | 看到目标字就快速点击，锻炼反应力 |
| 🃏 记忆翻牌 | 翻开卡片找到配对，训练记忆力 |
| 👂 听音选字 | 听发音选出正确的字，训练听力 |
| ⏱️ 计时挑战 | 60秒内答对尽可能多的题目 |

## 💻 下载安装

👉 **[点击这里前往下载页面](../../releases/latest)**（无需登录，任何人均可下载）

### Windows 用户
1. 点击上方下载链接，进入最新版本页面
2. 下载 `儿童识字游戏.exe`
3. 双击运行，无需安装

### Mac 用户
1. 点击上方下载链接，进入最新版本页面
2. 下载 `儿童识字游戏-Mac.zip`
3. 解压后将 `儿童识字游戏.app` 拖入「应用程序」文件夹
4. 双击运行

> ⚠️ Mac 首次运行若提示"无法验证开发者"，请前往「系统设置 → 隐私与安全性」，点击「仍要打开」即可。

## 🛠️ 开发者运行

需要 Python 3.8+ 环境：

```bash
# 安装依赖
pip install pygame

# 运行游戏
python word_game.py
```
